# lazygit

🇷🇺 [Русская версия](README.ru.md)

Config for [lazygit](https://github.com/jesseduffield/lazygit), git in a TUI (`gg`).

| File | What |
|---|---|
| `config.yml` | colors (recolored by `theme`), delta as pager |

**Installed by `install.sh` as symlinks:**

- `config.yml` → `~/Library/Application Support/lazygit/config.yml`
