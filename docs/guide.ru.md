# Как этим пользоваться

Всё, что умеет твоя настройка, — по разделам, с командами. Как это устроено внутри — в
[how-it-works.ru.md](how-it-works.ru.md), если Mac сбросился — [recovery.ru.md](recovery.ru.md).

Забыл команду — нажми **`?`** (или `ctrl+/`) в терминале: шпаргалка со всеми командами и хоткеями.
Начал набирать — жми **`Tab`**: подскажет варианты (темы, обои, стили фона, команды `dot`).

---

## Самое частое

| Команда | Что делает |
|---|---|
| `p` | перейти в проект из `~/dev` (выбор с превью) |
| `pl` | все проекты разом: ветка, изменения, давно ли коммит |
| `up` | запустить проект: база в Docker + приложение с hot reload |
| `got` / `gotw` | тесты / тесты заново при каждом сохранении |
| `gco` | переключить ветку git (с выбором) |
| `theme` · `wall` · `backdrop` | тема · обои · фон терминала |
| `update` | обслуживание раз в неделю |
| `dot doctor` | всё ли в порядке |
| `?` | шпаргалка |

## 1. Внешний вид: тема, обои, фон терминала

Три независимые вещи, которые работают вместе:

```
theme  ──▶ цвета всего (терминал, промпт, иконки) + обои этой темы
wall   ──▶ только обои (любые), цвета не трогает
backdrop ─▶ свечение за текстом терминала — из цветов ТЕКУЩИХ обоев
```

Цепочка сама: сменил тему → поставились её обои → фон терминала пересобрался под их цвета.
Сменил обои через `wall` → фон терминала тоже пересобрался. Тему при этом `wall` не меняет.

**После любой смены в Ghostty нажми `cmd+shift+,`** — он перечитает конфиг и покажет новое.

### Тема — `theme`

```bash
theme            # выбор с превью цветов
theme vesper     # сразу (по умолчанию)
theme kanagawa
```

Перекрашивает терминал, промпт, подсветку команд, eza, bat, lazygit, git diff, иконки приложений
и папок, ставит обои темы. Картинки всех тем — [themes.md](themes.md).

**Светлый режим.** Когда macOS переключается в светлое оформление (Настройки → Оформление),
Ghostty сам становится светлым (**Dev Day**), Zed тоже. Промпт и цвета команд — в **новых** окнах
(в уже открытом: `exec zsh`). Закрепить одно независимо от macOS: `export DOTFILES_APPEARANCE=dark`
(или `light`) в `~/.zshenv`.

`palette` — показать цвета текущей темы.

### Обои — `wall`

```bash
wall             # список с превью картинки прямо в терминале, Enter — поставить
wall eclipse     # сразу
wall sakura      # твои фото — в том же списке
```

- **Живые обои** (eclipse, orbit, aurora… — 25 штук) нарисованы кодом и **меняются в течение дня**:
  утро, день, вечер, ночь. Галерея — [wallpapers.md](wallpapers.md).
- **Твои фото** (sakura, fog, snow…): статичные, увеличены под экран без мыла.
- Ставятся на **все рабочие столы** сразу.

**Добавить своё фото:**

```bash
wall add ~/Downloads/фото.jpg rain     # rain — имя, под которым оно будет в списке
```

Маленькое или сжатое фото обработается само: убирается шум JPEG, увеличивается под экран
(2560×1664), обрезается по центру, добавляется лёгкая резкость. Фото лежат в
`~/dotfiles/wallpapers/photos/` — эта папка в `.gitignore`, на GitHub не уходит.

### Фон терминала — `backdrop`

```bash
backdrop          # выбор стиля с превью
backdrop glow     # сразу
backdrop off      # убрать фон
```

| Стиль | Как выглядит |
|---|---|
| **glow** | свет цветов обоев из правого нижнего и левого верхнего угла |
| **aurora** | волнистые ленты сияния вдоль нижнего края |
| **haze** | мягкое размытое облако света самих обоев |
| **glass** | сами обои, еле видные, как сквозь матовое стекло |
| **off** | без фона |

Из обоев берутся только цветные блики, тёмное прозрачно — поэтому фон подходит и тёмной теме,
и светлой. Стиль запоминается; при `wall` и `theme` фон пересобирается сам.
Картинка стилей — в README, раздел *Terminal backdrop*.

## 2. Терминал

### Промпт

```
╭─[dev@van1dal]─[logsence/internal]─[ main +1 !2 ?3 ⇡1]─[ 1.27.1 󰡨 ⎈ orbstack]    󱎫 3s · 13:42
╰─$
```

| Кусок | Что значит |
|---|---|
| `dev@van1dal` | пользователь@компьютер; по SSH компьютер красный |
| путь | от корня git-репозитория, имя проекта жирным |
| `+1` `!2` `?3` | в индексе · изменено · новые файлы |
| `⇡1` `⇣2` | не запушено · не подтянуто с GitHub |
| ` 1.27.1` | версия Go из `go.mod` |
| `󰡨` | в проекте есть docker-compose |
| `⎈ orbstack` | контекст Kubernetes — только в k8s-проекте или после `kubectl`/`helm` в этом окне |
| `✘ 1` | прошлая команда упала (код ошибки) |
| `󱎫 3s` | сколько шла прошлая команда (если дольше 2 с) |

После Enter старый промпт сворачивается до `$ команда` — история чистая.

### Плавный курсор

Курсор не прыгает, а скользит к новому месту, как в VS Code; на больших прыжках — светящийся
шлейф. Цвет из темы. Если курсор вдруг пропал: в `~/dotfiles/ghostty/config.ghostty`
закомментируй строки `cursor-opacity = 0` и `custom-shader = shaders/cursor_smooth.glsl`.

### Выпадающий терминал — `ctrl+\``

Выезжает сверху **из любого приложения**, на мониторе с мышкой; прячется, когда кликаешь мимо.
Нужно одно: **у Ghostty должен быть «Универсальный доступ»** (Настройки → Конфиденциальность и
безопасность → Универсальный доступ → Ghostty). Без него работает только внутри Ghostty.
`dot doctor` проверяет это сам.

Ghostty всегда работает в фоне: стартует при входе, `cmd+q` закрывает только окна.

### Приветствие и напоминания

В каждом новом окне — логотип и сводка (память, время работы), совет-команда дня и,
**только если есть повод**:

```
  󰚰  update не запускался 9 дн. · update
  󰊢  не запушено: pulse ⇡2 · watchdog !3 · pl
```

`⇡` — коммиты, которых нет на GitHub (пропадут при сбросе Mac), `!` — незакоммиченные файлы.
Выключить напоминания: `export NO_REMINDERS=1` в `~/.zshenv`.

### Удобства

| Команда | Что делает |
|---|---|
| `ctrl+r` | поиск по истории команд (atuin) |
| `ctrl+t` / `alt+c` | найти файл / перейти в папку (fzf) |
| `z часть-пути` | прыжок в папку, где бывал |
| `y` | файловый менеджер yazi (выйдешь — останешься в папке) |
| `c` | очистить экран (промпт наверх) |

| `weather Moscow` | погода |
| `j файл.json` | интерактивный просмотр JSON |

## 3. Проекты и Go

| Команда | Что делает |
|---|---|
| `p` / `p logs` | перейти в проект (с фильтром) |
| `pl` | все проекты: стек, ветка, изменения, давность |
| `up` | поднять зависимости из compose (postgres…) и запустить приложение с `.env` (air, иначе `go run`) |
| `dcd` | остановить зависимости |
| `got` · `gotw` · `gotv` | тесты · с перезапуском при сохранении · подробно |
| `gol` | golangci-lint |
| `vuln` | уязвимости: govulncheck + trivy |
| `db` | pgcli к базе проекта (из `DATABASE_URL` / `.env`) |
| `load` | нагрузочный тест (`load http://localhost:8080/health 10 50`) |
| `pd` | `dot project doctor` — что есть в проекте и чего не хватает |

### Новый проект — `gonew`

```bash
gonew myapi        # в ~/dev/myapi
gonew myapi --gh   # + сразу приватный репозиторий на GitHub и push
```

Сразу есть: Gin + Postgres, `/health` с тестом, graceful shutdown, Dockerfile, compose,
миграции, `make help`, air, golangci-lint, **CI на GitHub** (тесты, линтер, уязвимости, Docker),
README со значком CI. Перед первым коммитом шаблон сам проверяет, что всё собирается и тесты зелёные.

## 4. Git

| Команда | Что делает |
|---|---|
| `gs` · `gd` · `gds` | статус · diff · diff того, что в индексе |
| `gaa` · `gcm "текст"` · `gp` | добавить всё · коммит · push |
| `gg` | lazygit — git в интерфейсе |
| `gco` | переключить ветку (выбор, превью коммитов) |
| `git undo` | отменить последний коммит, изменения останутся |
| `git amend` | дописать в последний коммит |
| `git wip` / `git unwip` | быстро сохранить всё коммитом «wip» / снять его |
| `git fixup` | поправка к старому коммиту (выбор), сольётся при `rebase -i` |
| `git recent` | последние 10 веток |
| `git gone` / `git tidy` | ветки, удалённые на GitHub / удалить их у себя |

- `git pull` делает rebase (без лишних merge-коммитов), `git push` сам создаёт ветку на GitHub.
- **Перед каждым коммитом gitleaks** ищет пароли и токены — если нашёл, коммит не пройдёт.
  Ложная тревога — допиши в строку комментарий `gitleaks:allow`.
- В самом dotfiles **перед каждым push** запускаются проверки и тесты — сломанное не уйдёт.

## 5. Docker и Kubernetes

| Команда | Что делает |
|---|---|
| `dsh` | зайти в контейнер (выбор) |
| `dlogs` | логи контейнера (выбор) |
| `dc` · `dcu` · `dcd` · `dcl` | docker compose · up -d · down · logs -f |
| `lzd` | lazydocker |
| `k` | kubectl |
| `kx` / `kn` | сменить кластер / namespace |
| `klogs имя` | логи всех подов по имени (stern) |
| `tf` | OpenTofu (Terraform) |

Docker — это **OrbStack**: память берётся только пока работают контейнеры. Если спит — `up` его разбудит.

### Настройки macOS — `macos.sh`

```bash
~/dotfiles/macos.sh              # ПЛАН: что изменится («сейчас → станет»), ничего не меняет
~/dotfiles/macos.sh --yes        # применить
~/dotfiles/macos.sh --yes apps   # только одну группу
```

Группы: `keyboard` `trackpad` `finder` `saving` `screenshots` `dock` `appearance` `apps` `login`.
- `apps` — файлы кода (.json, .yaml, .sh, .sql, .env…) открываются в Zed. macOS спросит
  подтверждение на каждое расширение — запускать, сидя за Mac.
- `login` — Raycast при входе.

Скриншоты и записи экрана (`cmd+shift+5`) — в `~/Pictures/Screenshots`.

## 7. Zed и GoLand

- **Zed**: темы **Dev Night** (тёмная) и **Dev Day** (светлая) переключаются вместе с macOS,
  свои иконки файлов. Расширения ставятся сами: Go-линтер, GitHub Actions, Postgres-SQL,
  опечатки, Docker, Helm, .http-запросы. `ctrl-r` — задачи, `f5` — отладка.
- **GoLand**: те же темы — плагин из
  [релиза](https://github.com/van1dalgrr-arch/dotfiles/releases/tag/jetbrains-v1.0.0)
  (Settings → Plugins → ⚙️ → Install Plugin from Disk) или только цвета кода — `.icls`
  (Settings → Editor → Color Scheme → ⚙️ → Import Scheme). Подробно — [jetbrains/README.md](../jetbrains/README.md).

## 8. Новый Mac
