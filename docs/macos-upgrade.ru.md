# Обновление macOS (мажорное, например 26 → 27)

Чек-лист на один вечер. Всё, что можно проверить командой, — проверяется командой.

## До обновления

1. **Всё сохранено на GitHub**
   ```bash
   cd ~/dotfiles && git status -sb      # «ahead N» — есть неотправленное
   git push                             # pre-push сам прогонит make check и смоук-тесты
   git -C wallpapers/photos status -sb  # фото — в приватном dotfiles-photos
   ```
2. **Бэкап.** Time Machine на внешний диск: Настройки → Основные → Time Machine → «Создать сейчас».
   `dot doctor` предупредит, если бэкапов нет.
3. **Обновить приложения** — свежие версии чаще уже знают новую macOS:
   `update` (brew, Go-утилиты), отдельно — AeroSpace, OrbStack, Raycast (у них свои апдейтеры).
4. **Снимок системы «до»:** `dot snapshot`
5. Закрыть OrbStack с контейнерами (`lean on` или вручную), чтобы VM не мешала установке.

## После обновления

1. **Command Line Tools** — после мажорного обновления часто слетают, а без них не работают brew, git и cgo:
   ```bash
   xcode-select --install               # если git ругается на «invalid active developer path»
   ```
2. **Снимок «после» и сравнение:**
   ```bash
   dot snapshot && dot snapshot diff    # что сбросилось: настройки, объекты входа, разрешения
   ```
3. **Проверка всего:** `dot doctor --deep` — каждая проблема с командой, которая её чинит.
4. **Разрешения.** Если AeroSpace не двигает окна или ctrl+` не работает: Настройки →
   Конфиденциальность и безопасность → Универсальный доступ → выключить и снова включить AeroSpace (и Raycast).
5. **Настройки macOS**, если `snapshot diff` показал разъехавшиеся: `./macos.sh` (план) → `./macos.sh --yes`.
   Файлы кода в Zed: `./macos.sh --yes apps` (macOS спросит про каждый тип — делать у экрана).
6. **brew:** `brew doctor`, `brew upgrade` — формулы под новую систему могут пересобраться.
7. **Обои и тема:** `theme <текущая>` пересоберёт иконки и поставит обои на все столы.
8. **Go-проекты с cgo** (sqlite, некоторые драйверы): `go clean -cache` и пересобрать.
