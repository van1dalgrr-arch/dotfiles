# Горячие клавиши

🇬🇧 [English version](hotkeys.md) · [все документы](README.ru.md)

AeroSpace, Ghostty, `orbstack`, Zed, Rune и Neovim. В терминале `?` (или `ctrl+/`) покажет их все, плюс каждую функцию и алиас.

## AeroSpace — окна и рабочие столы

Хоткеи работают на любой раскладке, и на русской тоже.

| Клавиши | Что делают |
|---|---|
| `alt-enter` | новый терминал |
| `alt-e` | файловый менеджер (yazi) |
| `alt-q` | закрыть окно |
| `alt-h/j/k/l` | фокус влево / вниз / вверх / вправо |
| `alt-shift-h/j/k/l` | переместить окно |
| `alt-1…9` | перейти на рабочий стол |
| `alt-shift-1…9` | отправить окно на стол (и перейти за ним) |
| `alt-tab` | предыдущий стол |
| `alt-shift-tab` | перенести стол на следующий монитор |
| `alt-/` · `alt-,` | раскладка: плитка · аккордеон |
| `alt-shift-f` | на весь экран |
| `alt-shift-space` | плавающее ↔ плитка |
| `alt-minus` · `alt-equal` | уже · шире |
| `alt-r` | режим размера: `hjkl`, выход — `enter`/`esc` |
| `alt-shift-;` | служебный режим: `r` выровнять раскладку, `f` плавающее, `backspace` закрыть все, кроме этого, `esc` перечитать конфиг |
| `alt-shift-c` | перечитать конфиг |

Столы: 2 — код, 3 — браузер, 4 — чаты, 5 — музыка; терминал — там, где открыл.

## Ghostty — терминал

| Клавиши | Что делают |
|---|---|
| `` ctrl+` `` | выпадающий терминал из любого приложения |
| `cmd-t` · `cmd-w` | новая вкладка (в заголовке окна) · закрыть |
| `cmd-d` · `cmd-shift-d` | разделить вправо · вниз |
| `cmd-alt-стрелки` | между половинками |
| `cmd-shift-enter` | развернуть половинку |
| `cmd-shift-e` | выровнять половинки |
| `cmd-q` | закрыть окна (Ghostty остаётся в фоне, `` ctrl+` `` работает) |
| `cmd-shift-,` | перечитать конфиг (нужно редко: `theme`, `wall`, `backdrop` делают это сами) |

## `orbstack` — контейнеры

| Клавиши | Что делают |
|---|---|
| `↑↓` `j k` · колесо · клик | выбрать контейнер (второй клик — действия) |
| `g` · `G` | первый · последний |
| `enter` | действия с пояснением и командой docker |
| `l` · `s` | лог вживую · терминал внутри |
| `r` · `x` · `d` | перезапуск · стоп/старт · удалить |
| `i` · `f` · `c` | внутренности · Dockerfile · compose-файл |
| `n` · `t` · `w` | новый по шаблону · мониторинг · живая сборка |
| `u` · `U` | compose: поднять · остановить (проект в этой папке) |
| `e` · `E` | включить · выключить движок |
| `?` · `q` | все клавиши · выход |

В просмотре (`i`, `f`, `c`): `↑↓` прокрутка, `g`/`G` начало/конец, `esc` — назад.

## Zed — редактор

| Клавиши | Что делают |
|---|---|
| `ctrl-r` | меню задач: `up`, `air`, тесты, покрытие, линтер, логи compose, `curl /health` |
| `ctrl-t` | тест под курсором |
| `f5` | отладка через Delve: `cmd/api`, текущий пакет или тест под курсором |
| `ctrl-shift-r` | повторить последнюю задачу |
| `alt-g` · `alt-d` | lazygit · lazydocker внутри Zed |
| `cmd-j` | терминал |
| `cmd-1` · `cmd-2` · `cmd-3` | файлы · структура · git |
| `cmd-0` · `cmd-9` | левая · правая панель |
| `cmd-shift-d` | все ошибки проекта |
| `cmd-shift-b` · `cmd-alt-b` | git blame · blame в строке |
| `alt-up` · `alt-down` | строку вверх · вниз |
| `cmd-alt-l` | текст по центру |

Сниппеты Go: `iferr`, `iferrw`, `ginh`, `ginbind`, `ginr`, `ginmw`, `ttest`, `htest`, `bench`, `qrow`, `slog`, `jstruct`, `ctxt`.

Ещё: golangci-lint работает как языковой сервер (предупреждения прямо в коде), а файлы `.http` отправляют запросы
к твоему API, как REST Client в VS Code.

## Rune — IDE (раскладка GoLand)

| Клавиши | Что делают |
|---|---|
| `cmd-B` · `cmd-alt-B` · `alt-F7` · `F1` | определение · реализации · где используется · документация |
| `cmd-O` · `cmd-shift-O` · `cmd-E` · `cmd-shift-T` | тип · файл · недавние · тест ↔ код |
| `ctrl-T` · `shift-F6` · `ctrl-alt-O` | все рефакторинги · переименовать · импорты |
| `ctrl-alt-R` · `ctrl-shift-R` · `ctrl-alt-T` | запуск · тест под курсором · все тесты |
| `ctrl-alt-D` · `cmd-F8` · `F8` / `F7` / `shift-F8` | отладка · точка останова · шаги |
| `ctrl-alt-L` · `ctrl-alt-E` · `ctrl-alt-W` | линтер · ошибки сборки · vet и тесты в фоне |

Всё остальное — в [rune/README.ru.md](../rune/README.ru.md). F-клавиши — через `fn`.

## Neovim — LazyVim

| Клавиши | Что делают |
|---|---|
| `alt-o` · `alt-g` · `alt-p` · `alt-a` · `alt-d` · `alt-t` | orbstack · lazygit · Postman · эндпоинты · база · задачи — одним нажатием |
| `пробел` | меню всех действий с подсказками |
| `пробел f f` · `пробел /` · `пробел e` | файл · текст по проекту · дерево файлов |
| `gd` · `gr` · `K` · `пробел c r` · `пробел c a` | определение · где используется · документация · переименовать · действия с кодом |
| `пробел t r` · `пробел d b` · `пробел d c` | тест под курсором · точка останова · запустить отладку |
| `пробел r x` · `пробел r X` | ▶ запустить `func main` / тест под курсором · под отладчиком |
| `gpd` · `gpr` · `gpi` · `пробел c h` | посмотреть определение / использования / реализации во всплывашке · кто вызывает |
| `пробел c x` · `пробел c i` · `пробел c w` · `S-F6` | вынести · встроить · переписать · переименовать |
| `пробел G …` | Go: теги, реализовать интерфейс, `if err`, тесты, покрытие |
| `пробел g v` · `пробел g m` · `пробел U` | diffview и конфликты · ветка против main · история правок файла |
| `ctrl-n` · `пробел a c` · `пробел h` | мультикурсор · Claude Code · **шпаргалка** |
| `alt-c` · `пробел a x` · `alt-w` | спрятать/показать Claude · «почини ошибку» · gw во всплывашке |
| `alt-s` | тема с предпросмотром, `enter` — запомнить |

Все клавиши — [шпаргалка по Neovim](nvim.ru.md) (в nvim — `пробел h`), устройство — [nvim/README.ru.md](../nvim/README.ru.md).
