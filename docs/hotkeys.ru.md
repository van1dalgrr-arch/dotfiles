# Горячие клавиши

🇬🇧 [English version](hotkeys.md) · [все документы](README.ru.md)

AeroSpace, Ghostty, `orbstack` и Zed. В терминале `?` (или `ctrl+/`) покажет их все, плюс каждую функцию и алиас.

## AeroSpace — окна и рабочие столы

Хоткеи работают на любой раскладке, и на русской тоже.

| Клавиши | Что делают |
|---|---|
| `alt-enter` | новый терминал |
| `alt-e` | файловый менеджер (yazi) |
| `alt-q` | закрыть окно |
| `alt-h/j/k/l` | фокус влево / вниз / вверх / вправо |
| `alt-shift-h/j/k/l` | переместить окно |
| `alt-1…9` | перейти на рабочий стол |
| `alt-shift-1…9` | отправить окно на стол (и перейти за ним) |
| `alt-tab` | предыдущий стол |
| `alt-shift-tab` | перенести стол на следующий монитор |
| `alt-/` · `alt-,` | раскладка: плитка · аккордеон |
| `alt-shift-f` | на весь экран |
| `alt-shift-space` | плавающее ↔ плитка |
| `alt-minus` · `alt-equal` | уже · шире |
| `alt-r` | режим размера: `hjkl`, выход — `enter`/`esc` |
| `alt-shift-;` | служебный режим: `r` выровнять раскладку, `f` плавающее, `backspace` закрыть все, кроме этого, `esc` перечитать конфиг |
| `alt-shift-c` | перечитать конфиг |

Столы: 2 — код, 3 — браузер, 4 — чаты, 5 — музыка; терминал — там, где открыл.

## Ghostty — терминал

| Клавиши | Что делают |
|---|---|
| `` ctrl+` `` | выпадающий терминал из любого приложения |
| `cmd-d` · `cmd-shift-d` | разделить вправо · вниз |
| `cmd-alt-стрелки` | между половинками |
| `cmd-shift-enter` | развернуть половинку |
| `cmd-shift-e` | выровнять половинки |
| `cmd-q` | закрыть окна (Ghostty остаётся в фоне, `` ctrl+` `` работает) |
| `cmd-shift-,` | перечитать конфиг (нужно редко: `theme`, `wall`, `backdrop` делают это сами) |

## `orbstack` — контейнеры

| Клавиши | Что делают |
|---|---|
| `↑↓` `j k` · колесо · клик | выбрать контейнер (второй клик — действия) |
| `g` · `G` | первый · последний |
| `enter` | действия с пояснением и командой docker |
| `l` · `s` | лог вживую · терминал внутри |
| `r` · `x` · `d` | перезапуск · стоп/старт · удалить |
| `i` · `f` · `c` | внутренности · Dockerfile · compose-файл |
| `n` · `t` · `w` | новый по шаблону · мониторинг · живая сборка |
| `u` · `U` | compose: поднять · остановить (проект в этой папке) |
| `e` · `E` | включить · выключить движок |
| `?` · `q` | все клавиши · выход |

В просмотре (`i`, `f`, `c`): `↑↓` прокрутка, `g`/`G` начало/конец, `esc` — назад.

## Zed — редактор

| Клавиши | Что делают |
|---|---|
| `ctrl-r` | меню задач: `up`, `air`, тесты (и с `-race`), покрытие, линтер, govulncheck, миграции, sqlc, логи compose, `curl /health` |
| `ctrl-t` | тест под курсором |
| `f5` | отладка через Delve: `cmd/api`, текущий пакет, тест под курсором или подключиться к `dlv` в контейнере |
| `ctrl-shift-r` | повторить последнюю задачу |
| `alt-g` · `alt-d` | lazygit · lazydocker внутри Zed |
| `cmd-j` | терминал |
| `cmd-1` · `cmd-2` · `cmd-3` | файлы · структура · git |
| `cmd-0` · `cmd-9` | левая · правая панель |
| `cmd-shift-d` | все ошибки проекта |
| `cmd-shift-b` · `cmd-alt-b` | git blame · blame в строке |
| `alt-up` · `alt-down` | строку вверх · вниз |
| `cmd-alt-l` | текст по центру |

Сниппеты Go: `iferr`, `iferrw`, `ginh`, `ginbind`, `ginr`, `ginmw`, `ttest`, `htest`, `bench`, `qrow`, `slog`, `jstruct`, `ctxt`.
SQL: `mtable`, `mdrop`, `mcol`, `mindex`, `mfk`, `mtouch` (миграции), `qone`, `qmany`, `qins`, `qexec` (sqlc).
Dockerfile: `dgo` (сборка с кэшем, distroless), `ddlv` (под Delve). Compose/k8s: `cpg`, `credis`, `cdep`, `cwatch`, `kprobe`.

Ещё: golangci-lint работает как языковой сервер (предупреждения прямо в коде), а файлы `.http` отправляют запросы
к твоему API, как REST Client в VS Code.
