# Postman в nvim — за 5 шагов

🇬🇧 [English version](postman.md) · [все документы](README.ru.md)

**Что это:** отправить запрос своему API и увидеть ответ — не выходя из редактора.
Запросы лежат в обычном текстовом файле `api.http`. Никаких программ ставить не надо.

---

## Шаг 1. Запусти свой API

В терминале, в папке проекта:

```bash
up            # или: go run ./cmd/api
```

Проверь, что он отвечает (должен прийти ответ, а не тишина):

```bash
curl localhost:8080/health
```

## Шаг 2. Открой проект в nvim

```bash
nvim .
```

## Шаг 3. Нажми `alt-p`

Одно сочетание: левый **option** + **p** (или по очереди **пробел**, **r**, **h** — то же самое).

Появится файл `api.http` — в нём уже записаны **все** запросы твоего API. Выглядит так:

```http
@host = http://localhost:8080

### POST /auth/login → h.Login
# @name login
POST {{host}}/auth/login
Content-Type: application/json

{}

### GET /api/me → h.Me
GET {{host}}/api/me
Authorization: Bearer {{login.response.body.$.access_token}}
```

Каждый кусок между `###` — это **один запрос**.

## Шаг 4. Поставь курсор на запрос и нажми `Enter`

Справа откроется ответ:

```
┌─ api.http ───────────────────────┬─ ответ ─────────────────────────────┐
│ ### POST /auth/login             │ // POST /auth/login → 200 · 12 мс   │
│ POST {{host}}/auth/login   ◀ тут │ {                                   │
│ Content-Type: application/json   │   "access_token": "eyJhbGciOi..."   │
│                                  │ }                                   │
│ {"email": "a@b.c", ...}          │                                     │
└──────────────────────────────────┴─────────────────────────────────────┘
```

Первая строка ответа: **метод, адрес → код ответа · сколько шёл**.
`200` — всё хорошо, `400` — ты прислал что-то не то, `401` — нужен вход, `404` — нет такого адреса, `500` — упал сервер.

Закрыть ответ — `Esc`.

## Шаг 5. Поменяй запрос и отправь ещё раз

Тело запроса — то, что после пустой строки. Было `{}`, пишешь своё:

```http
POST {{host}}/auth/login
Content-Type: application/json

{"email": "me@example.com", "password": "secret"}
```

`Enter` — отправить. Файл сохраняется сам.

---

## Как работает вход (токен)

1. Отправь запрос **логина** (он первый в файле, у него есть строчка `# @name login`).
2. Всё. Остальные запросы сами берут токен из его ответа — это делает строчка
   `Authorization: Bearer {{login.response.body.$.access_token}}`.

Если токен в ответе называется иначе (например `token`), поправь конец строчки: `$.token`.

## Все клавиши

| Клавиши | Что делают |
|---|---|
| `alt-p` (или `пробел r h`) | создать `api.http` (если уже есть — просто открыть) |
| `Enter` | отправить запрос под курсором |
| `пробел R r` | отправить последний запрос ещё раз |
| `пробел R c` | скопировать запрос как команду `curl` |
| `пробел R n` · `пробел R p` | к следующему · к предыдущему запросу |
| `Esc` | закрыть ответ |

## Если что-то не так

| Видишь | Что делать |
|---|---|
| `→ нет ответа` | API не запущен — шаг 1. Запущен, а `curl localhost:8080/health` висит — VPN (Happ) перехватывает localhost: переключи его из TUN-режима или добавь localhost в исключения |
| `→ 401` | сначала отправь логин, потом этот запрос |
| `→ 404` | адрес неверный — сравни с `пробел r e` (список всех эндпоинтов) |
| порт не тот | первая строка файла: `@host = http://localhost:ТВОЙ_ПОРТ` |
| `Enter` ничего не делает | курсор не на запросе — поставь его на строку с `GET` / `POST` |
| хочу файл заново | удали `api.http` и снова `пробел r h` |

Ещё: `пробел r e` — список всех эндпоинтов, `ctrl-r` в нём — отправить запрос прямо оттуда.
Как это устроено внутри — [nvim/README.ru.md](../nvim/README.ru.md#postman-в-файле).
