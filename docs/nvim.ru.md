# Шпаргалка по Neovim

🇬🇧 [English version](nvim.md) · [все документы](README.ru.md) · [nvim/README](../nvim/README.ru.md)

Внутри nvim эта страница открывается по `пробел h` (и клавишей `h` на стартовом экране).
Нажми `пробел` и подожди полсекунды — появится меню всех действий. `пробел s k` — поиск по всем клавишам.
Русская раскладка понимает все команды: `вв` = `dd`, `о`/`л` = `j`/`k`.

**Учишься на ходу:** серые метки в строке показывают, куда прыгнут `w` `b` `e` `$` `{` `}` (`пробел u P` — выключить),
а тренер подскажет короче, если жмёшь `jjjjj` (`пробел u H` — выключить, `пробел u R` — какие привычки чаще всего). Ничего не запрещается.

**Обозначения:** `пробел` — leader, `ctrl-x` — с Ctrl, `S-F6` — Shift+F6 (на HyperX — `Fn`+`Shift`+`6`).

## 1. Как думать в vim

Vim — это язык. **Команда = действие + куда**, как фраза: `d` (удали) + `w` (до следующего слова) = `dw`.
Цифра впереди — повтор: `3dd` — три строки. `.` повторяет последнюю правку — **главная клавиша vim**.

| Режим | Как войти | Зачем |
|---|---|---|
| **обычный** | `esc` | ходить и командовать — тут проводишь 80% времени |
| **вставка** | `i` `a` `o` … | печатать текст |
| **выделение** | `v` (символы) · `V` (строки) · `ctrl-v` (столбец) | выделить и сделать что-то с куском |
| **команда** | `:` | `:w`, `:q`, `:%s/…`, любая команда |

## 3. Править

**Действия** (ждут «куда»): `d` удалить · `c` удалить и печатать · `y` скопировать · `>` `<` отступ ·
`=` выровнять · `gu` `gU` в нижний / верхний регистр · `gc` закомментировать.
Удвоенное действие — над строкой: `dd` `cc` `yy` `>>` `gcc`.

**Объекты** (`i` — внутри, `a` — вместе с границами):

| Объект | Что это | Пример |
|---|---|---|
| `iw` · `aw` | слово | `ciw` — заменить слово под курсором |
| `i"` · `i'` · `` i` `` | строка в кавычках | `ci"` — переписать строку, `yi"` — скопировать |
| `i(` · `i{` · `i[` | содержимое скобок | `di(` — очистить аргументы, `ci{` — переписать тело |
| `if` · `af` | **функция** (тело / целиком) | `daf` — удалить функцию, `vif` — выделить тело, `yaf` — копировать |
| `ic` · `ac` | **тип** (struct, interface) | `yac` — скопировать тип целиком |
| `ia` · `aa` | **аргумент** | `cia` — заменить аргумент, `daa` — удалить вместе с запятой |
| `io` · `ao` | блок, цикл, условие | `dao` — убрать `if` целиком |
| `it` · `ip` | тег (HTML) · абзац | `yip` — скопировать блок кода |
| `iq` · `ib` | любые кавычки · любые скобки рядом | `ciq` — не важно, `"` или `` ` `` |

Читай вслух: `ci"` — «change inside quotes», `daf` — «delete a function». Дальше пальцы сами.

| Клавиши | Что |
|---|---|
| `i` · `a` · `I` · `A` | печатать перед курсором · после · в начале строки · в конце |
| `o` · `O` | новая строка ниже / выше |
| `x` · `r` + буква · `~` | удалить символ · заменить символ · сменить регистр |
| `u` · `ctrl-r` | отменить · вернуть |
| `.` | **повторить последнюю правку** (`ciw` новое слово → `n` → `.` → `n` → `.`) |
| `p` · `P` | вставить после / перед курсором |
| `J` | приклеить следующую строку к этой |
| `ctrl-a` · `ctrl-x` | число под курсором +1 / −1 (`10 ctrl-a` — +10) |
| `gcc` · `gc` + объект | комментарий на строку · `gcip` — на блок |
| `V` … `J` / `K` | выделенные строки вниз / вверх |
| `V` … `>` / `<` | сдвинуть выделенное (`.` — ещё раз) |

**Обёртки (surround):** `gsa` + объект + символ — обернуть (`gsaiw"` — слово в кавычки, `gsaiw)` — в скобки),
`gsd"` — снять кавычки, `gsr"`` ` — поменять `"` на `` ` ``, `gsr)]` — круглые скобки на квадратные.

**`ctrl-a` / `ctrl-x` не только для чисел:** `true`↔`false`, `&&`↔`||`, а в Go ещё `:=`↔`=`, `==`↔`!=`, `var`↔`const`,
`t.Error`↔`t.Fatal`, `slog.Debug`→`Info`→`Warn`, `Println`→`Printf`, `GET`→`POST`…, `StatusOK`→`StatusCreated`→…

**История копирования:** `пробел p` — всё, что копировал, списком; после `p` — `[y` / `]y` листают, что вставилось.

**В режиме вставки:** `jk` (быстро, в английской раскладке) — выйти, как `esc`; `ctrl-w` — стереть слово, `ctrl-u` — до начала строки, `ctrl-r "` — вставить скопированное, `ctrl-k` — подсказка параметров функции.

| Клавиши | Что |

## 6. Регистры и макросы

| Клавиши | Что |
|---|---|
| `"ayy` · `"ap` | скопировать в регистр `a` · вставить из него (26 буферов обмена) |
| `y` / `p` | работают с системным буфером macOS — ⌘V в другом приложении вставит |
| `пробел s "` | все регистры списком |
| `qa` … `q` | **записать макрос** в `a`: все нажатия до второго `q` |
| `@a` · `@@` · `20@a` | проиграть макрос · ещё раз · 20 раз |

Пример: поля структуры в `json:"…"` руками — `qa` … правка одной строки … `j0q`, потом `30@a`. (Для тегов есть `пробел G j` — но макросы умеют всё.)

## 9. Go: что появилось

**Тесты в фоне.** Сохранил Go-файл — через секунду идёт `go test` его пакета. Справа в статусной строке
`󰙨 ✓ 42` (все прошли), `󰙨 ✗ 1` (упал) или `✗ сборка` (не компилируется). Упавшая проверка подсвечивается
ошибкой прямо на своей строке в `_test.go`: `● TestAdd: got -1, want 3`. Починил — пометка исчезает.
Заодно обновляется покрытие: если оно показано (`пробел G V`), полоски слева перекрашиваются сами.
`пробел t A` — выключить / включить.

**▶ у функций.** Слева от `func main()`, `func TestX`, `BenchmarkX`, `FuzzX`, `ExampleX` — ▶.
Курсор где угодно внутри функции → `пробел r x`. main — `go run .` в терминале снизу; тест — через neotest
(✓/✗ появится рядом); бенчмарк — `go test -bench` с `-benchmem`; фаззинг — 30 секунд.
`пробел r X` — то же под отладчиком. В `_test.go` вне функции — весь файл.

**Генерация — группа `пробел G`** (только в Go-файлах):

| Клавиши | Что |
|---|---|
| `пробел G j` / `G y` / `G d` | теги `json` / `yaml` / `db` у полей структуры под курсором |
| `пробел G t` | свои теги: `json,validate` |
| `пробел G r` | убрать теги |
| `пробел G i` | реализовать интерфейс — курсор на имени типа, ввести `io.Reader` |
| `пробел G e` | `if err != nil { return … }` с правильными нулями для возвращаемых значений |
| `пробел G c` | doc-комментарий к функции / типу |
| `пробел G f` · `пробел G F` | тест для функции · для всего файла (gotests) |
| `пробел G m` · `пробел G g` | `go mod tidy` · `go get пакет` |
| `пробел G p` | **JSON → Go-структура**: вставь JSON (ответ API) — получишь структуру с тегами |
| `пробел G o` | оптимизации компилятора прямо в коде: что ушло в кучу, что заинлайнилось (ещё раз — убрать) |
| `пробел G v` · `G V` · `G s` | покрытие: прогнать и закрасить · спрятать · сводка |

**Сниппеты** — набери и выбери в подсказках (`tab` — к следующему полю):
`ife` `errw` `tt` (табличный тест) `bench` `gh` (Gin-хендлер) `gbind` (ShouldBindJSON + 400) `hf` (net/http)
`ctxf` `slog` `wg` (WaitGroup.Go) `new` (конструктор). Свои — в `nvim/snippets/go.json`.

**Надписи над кодом (codelens):** в `go.mod` — «обновить зависимость», `tidy`, `govulncheck`; над `//go:generate` — запуск.
`пробел c c` — выполнить надпись под курсором.

**Подсказки типов** серым внутри кода (`x := …` → тип) — `пробел u h` выключить / включить.
**Шапка функции** прилипает сверху при прокрутке длинной функции — `пробел u t` выключить.

**Отладка в Docker:** в контейнере запусти
`dlv debug ./cmd/api --headless --listen=:2345 --accept-multiclient --api-version=2`, пробрось порт 2345,
в nvim `пробел d c` → «Подключиться к dlv в Docker». Код в контейнере должен лежать в `/app`
(иначе поправь `substitutePath` в `nvim/lua/plugins/goland.lua`). Точки останова — как обычно.

**SQL в строках** (`` `SELECT …` ``, `"INSERT …"`) подсвечивается как SQL.

**Go-черновик:** `пробел r g` — пустой `main.go` в своём модуле, `пробел r x` — запустить. Как Go Playground.

**Структурная замена:** `пробел s A` — поиск и замена по смыслу кода (ast-grep), как Structural Search в GoLand.
Найти `errors.New(fmt.Sprintf($$$A))` → заменить `fmt.Errorf($$$A)` — по всему проекту, с превью.

**Точки останова сохраняются** между запусками nvim.

**Бенчмарки + профиль:** `пробел r r` → «бенчмарки пакета + pprof» — откроется браузер с flame graph.

| `пробел u B` | автор, дата и сообщение коммита — серым у текущей строки |
| `пробел g b` | история строки: кто менял, `enter` — весь коммит |
| `]h` `[h` · `пробел g h s` · `пробел g h r` | к изменённому куску · добавить кусок в коммит · откатить кусок |
| `пробел g h p` | показать, что было в куске до правки |
| `пробел g w` · `alt-w` | **gw** — GitHub во всплывающем окне: страницы PR с diff и ревью, Actions, Inbox, поиск, профиль; `alt-w` ещё раз — спрятать |
| `пробел U` | дерево правок файла (Local History): ходишь по дереву — файл сразу показывает тот вариант; ушёл из дерева — он и остался |

## 11. Мультикурсоры

| Клавиши | Что |
|---|---|
| `ctrl-n` | курсор на следующем таком же слове (как ⌃G); в выделении — на следующем таком же куске |
| `пробел m a` | курсоры на всех совпадениях |
| `пробел m s` · `пробел m N` | пропустить совпадение · назад |
| `пробел m j` · `пробел m k` | курсор строкой ниже / выше |
| `alt` + клик | поставить / убрать курсор мышью |
| `←` `→` · `пробел x` | пока курсоров несколько: переключаться · убрать текущий |
| `esc` | убрать все курсоры |
| `пробел m l` | выровнять курсоры в столбец |

Дальше — обычные команды vim, сразу на всех курсорах: `ciw`, `A;`, `dd`, `.`.

## 12. Claude Code внутри nvim

| Клавиши | Что |
|---|---|
| `пробел a c` | открыть / спрятать Claude справа |
| `пробел a f` | перейти в окно Claude |
| `пробел a b` | добавить текущий файл в контекст |
| `V` … `пробел a s` | отправить выделенный код |
| `пробел a a` · `пробел a d` | **принять / отклонить** правку — Claude показывает её diff-ом прямо в nvim |
| `пробел a r` · `пробел a C` | продолжить прошлую сессию (выбрать) · последнюю |
| `alt-c` | **спрятать / показать Claude откуда угодно** — и из самой панели Claude |
| `пробел a x` | **«почини»**: ошибка под курсором уходит в Claude вместе с местом в файле |
| `пробел a R` · `пробел a X` | **ревью ветки**: Claude читает diff против main (и незакоммиченное), замечания встают на строки, как ошибки линтера, и списком в `:copen` · убрать замечания |
| `:ClaudeCodeClose` | закрыть Claude совсем |

Claude видит, какой файл открыт и что выделено. Если Claude запущен в отдельном окне Ghostty — набери там `/ide`, и он подключится к этому nvim.

## 13. Внешний вид

- **Тема — tokyonight night**, прозрачная, как раньше.
- **`alt-s` — сменить тему** (или `пробел u C`): справа список, под ним твой код. Курсор по списку — весь редактор
  сразу в этой теме; `enter` — применить и **запомнить** (nvim дальше стартует с ней), `esc` — вернуть как было.
  Можно печатать имя: `dragon`, `dawn`, `fox`. 31 тема: tokyonight, kanagawa, rose-pine, nightfox/carbonfox,
  cyberdream, vesper, gruvbox-material, catppuccin — и светлые: `tokyonight-day`, `rose-pine-dawn`, `kanagawa-lotus`, `dayfox`.
- **`rose-pine` — в цветах терминала:** палитра из темы dotfiles (та же, что у Ghostty, starship, lazygit);
  `theme kanagawa` перекрашивает и его, светлый режим macOS — светлая Dev Day.
- **Фон прозрачный**, как у Ghostty; рамки у всех всплывающих окон.
- **Скриншот кода:** выдели строки → `пробел P` (без выделения — функция под курсором). PNG в окне с тенью,
  в цветах текущей темы, с номерами строк — сразу в буфере обмена (⌘V в Telegram) и в `~/Pictures/code`.
- **Совет дня** на стартовом экране — случайная строка из этой шпаргалки, каждый запуск новая.
- **`.env` под звёздочками:** пароли и токены скрыты, открыта только строка под курсором; `пробел u e` — показать всё.
- `пробел u w` перенос строк · `пробел u l` номера строк · `пробел u d` ошибки · `пробел u z` режим «дзен».
