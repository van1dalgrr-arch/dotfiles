# Тесты

🇬🇧 [English version](README.md)

Смоук-тесты `dot` и интеграционные тесты установщика. Без сети, ничего не ставят, настоящий HOME не трогают.

| Файл | Что это |
|---|---|
| `smoke.sh` | `make test`; ещё запускается в CI (Linux — переносимое, macOS — всё) и перед каждым push |
| `install.sh` | `install.sh` / `uninstall.sh` на копии репозитория во временном HOME: повторы, бэкапы (`.bak`, `.bak.1`), битые и чужие ссылки, возврат байт в байт |

## Запустить

```bash
make test        # оба набора
make check       # проверки, как в CI (shellcheck, синтаксис, шейдеры, Go-тесты, gitleaks)
```

Тесты установщика уже нашли три настоящие ошибки: второй файл на месте ссылки затирал первый `.bak`,
а чужие и битые ссылки удалялись без бэкапа. Новая ошибка — сначала тест, который её ловит.
