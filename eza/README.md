# eza

🇷🇺 [Русская версия](README.ru.md)

Colors for [eza](https://github.com/eza-community/eza), the modern `ls` (`ls`, `ll`, `lt` are aliases).

| File | What |
|---|---|
| `theme.yml` | reference colors in Rosé Pine; `theme` generates copies for the current and the light theme |

**Installed by `install.sh` as symlinks:**

- `theme.yml` → `~/.config/eza/theme.yml`
