# eza

🇬🇧 [English version](README.md)

Цвета для [eza](https://github.com/eza-community/eza) — современный `ls` (`ls`, `ll`, `lt` — алиасы).

| Файл | Что это |
|---|---|
| `theme.yml` | эталонные цвета Rosé Pine; `theme` генерирует копии для текущей и светлой темы |

**`install.sh` ставит симлинками:**

- `theme.yml` → `~/.config/eza/theme.yml`
