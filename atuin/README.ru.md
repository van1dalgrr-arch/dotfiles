# atuin

🇬🇧 [English version](README.md)

Конфиг [atuin](https://atuin.sh) — история команд в SQLite: `ctrl+r` открывает поиск, у каждой команды видны папка, код выхода и время.

| Файл | Что это |
|---|---|
| `config.toml` | компактный вид, превью, `↑` ищет только по текущей папке, без проверки обновлений |

**`install.sh` ставит симлинками:**

- `config.toml` → `~/.config/atuin/config.toml`

## Заметки

История живёт только на этом Mac (синхронизация выключена). Atuin AI выключен намеренно (`--disable-ai` в `.zshrc`), поэтому `?` открывает шпаргалку.
