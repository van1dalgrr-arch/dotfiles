# macOS helpers

🇷🇺 [Русская версия](README.ru.md)

Helpers for [macos.sh](../macos.sh).

| File | What |
|---|---|
| `default-apps.swift` | makes Zed the default app for code files; `macos.sh --yes apps` calls it |

## Note

macOS 26 asks to confirm each file type on screen, so run it while at the Mac.
