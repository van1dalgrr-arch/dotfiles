# Помощники macOS

🇬🇧 [English version](README.md)

Помощники для [macos.sh](../macos.sh).

| Файл | Что это |
|---|---|
| `default-apps.swift` | делает Zed программой по умолчанию для файлов кода; вызывается из `macos.sh --yes apps` |

## Важно

macOS 26 спрашивает подтверждение на каждое расширение — запускать, сидя за Mac.
