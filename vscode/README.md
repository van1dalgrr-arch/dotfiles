# VS Code

🇷🇺 [Русская версия](README.ru.md)

Settings for VS Code, the secondary editor (Zed is the main one).

| File | What |
|---|---|
| `settings.json` | editor settings and theme |
| `keybindings.json` | shortcuts |
| `extensions.txt` | extensions installed by `install.sh` |

**Installed by `install.sh` as symlinks:**

- `settings.json` → `~/Library/Application Support/Code/User/settings.json`
- `keybindings.json` → `~/Library/Application Support/Code/User/keybindings.json`
