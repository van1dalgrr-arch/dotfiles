# Zed tools

🇷🇺 [Русская версия](README.ru.md)

Generators for the Zed extensions.

| File | What |
|---|---|
| `light.py` | builds Dev Day from Dev Night (deeper accents for white backgrounds) |
| `preview.py` | renders `docs/zed-themes.png` without opening Zed |
| `build-icons.swift` | extracts Nerd Font glyphs into SVG icons |
