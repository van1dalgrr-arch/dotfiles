# Инструменты Zed

🇬🇧 [English version](README.md)

Генераторы для расширений Zed.

| Файл | Что это |
|---|---|
| `light.py` | собирает Dev Day из Dev Night (акценты глубже для белого фона) |
| `preview.py` | рисует `docs/zed-themes.png` без запуска Zed |
| `build-icons.swift` | вытаскивает значки Nerd Font в SVG |
