# btop

🇷🇺 [Русская версия](README.ru.md)

Config and theme for [btop](https://github.com/aristocratos/btop), the resource monitor (`top` is an alias for it).

| File | What |
|---|---|
| `btop.conf` | btop settings; most comments come from btop itself |
| `themes/rose-pine.theme` | reference theme; `theme` writes a recolored `dotfiles.theme` |

**Installed by `install.sh` as symlinks:**

- `btop.conf` → `~/.config/btop/btop.conf`
- `themes/rose-pine.theme` → `~/.config/btop/themes/rose-pine.theme`
