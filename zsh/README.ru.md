# zsh

🇬🇧 [English version](README.md)

Конфиг shell: свой промпт, алиасы, функции. Стартует за ~0.15 с. Все команды — [docs/guide.ru.md](../docs/guide.ru.md).

| Файл | Что это |
|---|---|
| `.zshrc` | PATH, oh-my-zsh, fzf, zoxide, atuin, алиасы, `p`, `pl`, `up`, `gco`, обёртка `docker` (сама запускает OrbStack), `orbstack` → [berth](../berth), приветствие |
| `prompt.zsh` | промпт в рамке, сворачивание, подсказки «команда не найдена» |
| `theme.zsh` | `theme`, `wall`, `wall add`, `backdrop`, `palette`, светлый режим |
| `reminders.zsh` | напоминания под приветствием: давно не было `update`, незапушенное |
| `backend.zsh` | `db`, `vuln`, `load`, алиасы Kubernetes |
| `gonew.zsh` | `gonew`: новый Go-проект с CI |
| `update.zsh` | `update`: обслуживание |
| `cheatsheet.zsh` | шпаргалка `?` / `ctrl+/` |
| `ram.zsh` | `ram`: память по приложениям |
| `completions/_dot` | дополнение по Tab для `dot`, `theme`, `wall`, `backdrop`, `awake` |

**`install.sh` ставит симлинками:**

- `.zshrc` → `~/.zshrc`

## Порядок загрузки

`.zshrc` подключает oh-my-zsh, потом `theme.zsh` (палитра первой — остальное берёт её цвета), промпт, утилиты и остальные модули. Подсветка синтаксиса — последней.

## Что умеет оболочка

- **Шпаргалка всегда под рукой:** `?` или `ctrl+/` — все хоткеи, функции и алиасы с поиском.
- **Промпт без тормозов:** вне git ни одного процесса, в git — один `git status`. После `enter` сворачивается до `$ команда`.
- **Подсказки, когда ошибся:** набрал команду, которой нет, — подскажет `brew install` и похожие свои команды.
- **Поиск везде через fzf:** `ctrl-t` — файл с превью, `alt-c` — папка, `tab` — дополнение с превью, `ctrl-r` — история (atuin).
- **Прыжки по папкам:** `z часть-пути` (zoxide) и `p` — проект из `~/dev`.
- **Память на 8 ГБ:** `ram` — кто ест память по приложениям, `lean on` / `lean off` — закрыть тяжёлое и вернуть.
- **Docker без «не могу подключиться»:** обёртка `docker` сама запускает OrbStack, если он выключен.
- **Сон:** `awake on` — не засыпать с закрытой крышкой (для работы с телефона), `awake off` — обратно.
