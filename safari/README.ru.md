# Safari

🇬🇧 [English version](README.md)

Браузер — Safari: на M2 с 8 ГБ он тратит меньше всех памяти и батареи. Его настройки — в `macos.sh safari`;
здесь только то, что Safari не принимает из терминала.

| Файл | Что это |
|---|---|
| `user.css` | таблица стилей для всех сайтов: JetBrains Mono для кода |

**Шрифт.** Safari → Настройки → Дополнения → Таблица стилей → Другая… → `⌘⇧G` → `~/dotfiles/safari/user.css`.
Выбор в самом Safari и даёт ему (он в песочнице) доступ к файлу. `dot doctor` проверяет.

**Обои.** Своя стартовая страница Safari: новая вкладка → правый клик → «Настроить стартовую страницу» →
«Фоновое изображение» → `+` → `⌘⇧G` → `~/Pictures/Wallpapers`. Синхронизируется через iCloud.
