# Safari

🇬🇧 [English version](README.md)

Браузер — Safari: на M2 с 8 ГБ он тратит меньше всех памяти и батареи. Здесь он получает стартовую страницу
с текущими обоями и цветами темы, закладки из текстового файла и JetBrains Mono для кода на всех сайтах.

| Файл | Что это |
|---|---|
| `start.html` | шаблон стартовой страницы: часы, дата, закладки на клавишах `1`–`9`, обои за ними |
| `links` | закладки, по одной на строку: `название  адрес` |
| `user.css` | таблица стилей для всех сайтов: JetBrains Mono в `code`/`pre`, выделение цветом акцента |
| `build.sh` | подставляет цвета темы, закладки и обои → `~/.cache/dotfiles/safari/` |

`theme` и `wall` пересобирают всё сами. После правки `links`: `safari/build.sh`.

## Настройка, один раз

Терминалу macOS не даёт менять настройки Safari (они в песочнице), поэтому это минута руками.
`dot doctor` потом проверит.

1. **Safari → Настройки → Основные.** «В новых окнах» и «В новых вкладках» открывать: **Домашнюю страницу**.
   Домашняя страница: `file:///Users/<ты>/.cache/dotfiles/safari/start.html`
2. **Настройки → Дополнения.** Таблица стилей → Другая… → `⌘⇧G` → `~/.cache/dotfiles/safari/user.css`.
   Там же включи **«Показывать полный адрес веб-сайта»** и **«Показывать функции для веб-разработчиков»**.

По желанию: **uBlock Origin Lite** из App Store (бесплатно).
Страницы без рекламы и трекеров легче — это экономит память.
