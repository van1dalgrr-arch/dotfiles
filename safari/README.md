# Safari

🇷🇺 [Русская версия](README.ru.md)

Safari is the browser: on an 8 GB M2 it uses the least memory and battery. Its settings are in `macos.sh safari`;
here is only what Safari can't take from the terminal.

| File | What |
|---|---|
| `user.css` | style sheet for every site: JetBrains Mono for code |

**Font.** Safari → Settings → Advanced → Style sheet → Other… → `⌘⇧G` → `~/dotfiles/safari/user.css`.
Picking it in Safari is what gives Safari (sandboxed) access to the file. `dot doctor` checks it.

**Wallpaper.** Safari's own Start Page: new tab → right-click → Customize Start Page → Background image → `+` →
`⌘⇧G` → `~/Pictures/Wallpapers`. Synced to your other devices through iCloud.
