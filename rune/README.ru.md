# Rune

🇬🇧 [English version](README.md) · [← dotfiles](../README.ru.md)

[Rune](https://rune.build) — IDE на Go с отрисовкой на видеокарте (Metal на macOS), всё с клавиатуры.
Go в ней — основной язык, и расширения тоже пишутся на Go. Это редактор, на который я постепенно
переезжаю с Zed: настроены оба, Zed остаётся основным, пока Rune не закроет всю ежедневную работу.

| Файл | Что это |
|---|---|
| `config.yaml` | личный конфиг → `~/.rune/config.yaml` (ссылку ставит `install.sh`): тема **Neon Noir** (Dev Night — `:guitheme dev-night`), раскладка как в **GoLand**, запуск/тесты/отладка/линтер одной клавишей |
| [`../bin/rune-go`](../bin/rune-go) | помощник для Go-команд: находит модуль и main-пакет от файла в фокусе, отдаёт ошибки lint/vet/build строками `путь:строка:колонка` для списка с переходом |
| `dot-ext/` | **`rune-dot`** — расширение Rune на Go (`rune-go-sdk`): `:work <режим>` / `:work off` вызывают `dot work` с дополнением имён режимов, `:projectdoctor` — `dot project doctor` для файла в фокусе; итог приходит уведомлением. Собирает `install.sh` в `~/go/bin/rune-dot`; тесты гоняют `make check` и CI |

## Клавиши — как в GoLand

Поверх пресета **standard**. AeroSpace забирает `alt-h/j/k/l`, `alt-r`, `alt-1…9` и `alt-shift-…`,
поэтому всё здесь — на `cmd`, `ctrl-alt`, `cmd-alt` и F-клавишах (на маке F-клавиши — через `fn`).
Все команды — `cmd-shift-p`, шпаргалка Rune — `cmd-/`.

| | Клавиша | Что |
|---|---|---|
| **Навигация** | `cmd-B` · `cmd-alt-B` · `cmd-shift-B` | определение · реализации (тип ↔ интерфейс) · тип |
| | `alt-F7` / `ctrl-cmd-U` · `F1` / `ctrl-J` | где используется · документация |
| | `cmd-O` · `cmd-shift-O` · `cmd-alt-O` · `cmd-E` | тип · файл · функция по проекту · открытые вкладки |
| | `cmd-shift-F` · `ctrl-alt-F` · `cmd-F12` | текст по проекту · git grep · структура файла |
| | `cmd-shift-T` · `cmd-[` / `cmd-]` | тест ↔ код · назад / вперёд |
| | `F2` / `shift-F2` · `alt-shift-E` | следующая / прошлая ошибка · все ошибки файла |
| **Рефакторинг** | `shift-F6` · `ctrl-alt-O` · `cmd-.` | переименовать · импорты · все безопасные исправления |
| | `ctrl-T` | все рефакторинги gopls списком (25 штук) |
| | `cmd-alt-M` · `cmd-alt-V` · `cmd-alt-C` · `cmd-alt-N` | вынести функцию · переменную · константу · встроить |
| | `cmd-alt-S` · `cmd-alt-T` | заполнить структуру · json-теги |
| **Запуск** | `ctrl-alt-R` | `go run` main-пакета во вкладке-задаче (`ctrl-R` в ней — перезапуск) |
| | `ctrl-shift-R` · `ctrl-alt-T` | тест под курсором · все тесты (перезапуск при сохранении) |
| | `ctrl-alt-W` | vet + тесты в фоне: квадраты по краям зелёные/красные |
| | `ctrl-alt-L` · `ctrl-alt-E` | golangci-lint · ошибки сборки — списком с превью и переходом |
| **Отладка** | `cmd-F8` / `ctrl-alt-B` | точка останова (ставь до запуска) |
| | `ctrl-alt-D` · `ctrl-shift-D` | отладка main-пакета · теста под курсором |
| | `F8` · `F7` · `shift-F8` · `cmd-alt-R` · `cmd-F2` | шаг · внутрь · наружу · дальше · стоп |
| | `ctrl-alt-↓` · `→` · `↑` | шаг · внутрь · наружу без F-клавиш |
| | `alt-F8` | вычислить выражение |
| **Git** | `ctrl-alt-G` · `ctrl-alt-H` · `ctrl-alt-A` | lazygit · история файла · история строки |
| | `ctrl-cmd-I` / `ctrl-cmd-K` | прошлое / следующее изменение |
| **Вкладки** | `cmd-shift-[` / `]` · `ctrl-1…9` | соседняя вкладка · вкладка по номеру |
| | `alt-W` · `cmd-alt-W` · `cmd-shift-W` | закрыть вкладку · все, кроме текущей · все |
| | `shift-tab` | показать / скрыть дерево файлов |

Ещё команды без клавиш: `:todo`, `:conflicts`, `:changed`, `:gocover` (покрытие в браузере), `:gowatchoff`,
`:govet`, `go tidy`, `go vulncheck`, `go add-test`, `go assembly`.

## Как в nvim — одно нажатие

Те же клавиши, что в [nvim](../nvim/README.ru.md), но клавиши редактора обычные (без vim-режима).
Логика общая: [`bin/rune-ide`](../bin/rune-ide) вызывает те же модули `nvim/lua/dotfiles`, правишь в одном месте.

| Клавиша | Что | Команда |
|---|---|---|
| `alt-O` | контейнеры (orbstack) | `:containers` |
| `alt-G` | lazygit (подсказка аргументов переехала на `ctrl-alt-P`) | `:lg` |
| `alt-P` · `ctrl-enter` | **Postman в файле**: `api.http` проекта (создаётся из маршрутов Gin) · отправить запрос под курсором | `:postman` · `:httpsend` |
| `alt-A` | **эндпоинты Gin** с полным путём, `enter` — к хендлеру | `:endpoints` |
| `alt-D` | база проекта (`db`) | `:db` |
| `alt-T` | **задачи** как в nvim: `up`, `air`, тесты, покрытие, бенчмарки, линтер, compose, docker build, hadolint, trivy… (`tab` — список) | `:task <имя>` |
| `alt-C` · `ctrl-alt-C` | Claude Code во вкладке · **ревью ветки** от Claude списком с переходом | `:claude` · `:review` |
| `ctrl-alt-S` | скриншот функции под курсором (freeze) → буфер обмена и `~/Pictures/code` | `:shot` |

Ещё без клавиш: `:gw` (PR и CI), `:ld` (lazydocker), `:yazi`, `:k8s` (k9s), `:backup`.
Определение и документация, которые раньше были на `alt-D` / `alt-T`, остались на `cmd-B` и `F1` / `ctrl-J`.

## Без трафика по умолчанию

Из коробки Rune шлёт телеметрию, раз в сутки проверяет обновления и при старте подключается к своей
сети (порт 7473). `config.yaml` выключает все три, так что сам Rune никуда не ходит: обновиться —
`:upgrade`, поднять сеть — `:network up`, когда понадобится.

## Установка

```sh
brew install unstablebuild/tap/rune     # есть и в Brewfile
```

При первом запуске Rune спросит раскладку клавиш (бери **standard** — как в Zed/VS Code) и запишет
её в `config.yaml`, то есть через ссылку в файл этого репозитория — посмотри diff и закоммить. Rune переписывает файл целиком, когда дописывает блоки своих пакетов (`go`, `fuzzy-search`) или сохраняет `:config`, — ссылка становится обычным файлом. Поэтому в репозитории конфиг лежит уже в формате Rune и с блоками пакетов: дописывать нечего, и ссылка живёт. Если всё же сломается, `dot doctor` предупредит и покажет, как вернуть.
`dot doctor` показывает Rune как необязательный и предупреждает, если расширение `dot` не собрано.

## Своё расширение

`dot-ext/` — маленький шаблон: в `main.go` только метаданные, права и регистрация команд, логика —
в `handler.go` за интерфейсами SDK, `handler_test.go` проверяет её на фейках.
Пересобранное расширение подхватывается без перезапуска: `extensions restart dot` в консоли Rune.
