# nvim

🇬🇧 [English version](README.md) · [← dotfiles](../README.ru.md)

Neovim на [LazyVim](https://lazyvim.org) — запасной выход, если Rune или Zed надоели: готовая IDE в терминале,
ничего не нужно собирать руками. Свою сборку с нуля потом можно начать в соседней папке и запускать через
`NVIM_APPNAME=<имя> nvim` — эта при этом не сломается.

| Файл | Что это |
|---|---|
| `init.lua` | одна строка: грузит `lua/config/lazy.lua` |
| `lua/config/lazy.lua` | ставит менеджер плагинов lazy.nvim и LazyVim; **проверка обновлений в фоне выключена** — обновить: `:Lazy update` |
| `lua/config/options.lua` | **русская раскладка понимает vim-команды** (`langmap`), 8 строк вокруг курсора |
| `lua/config/keymaps.lua` | F-клавиши отладки как в Rune и GoLand |
| `lua/config/autocmds.lua` | **автосохранение** (а с ним импорты и формат) и перечитывание файлов, изменённых снаружи |
| `lua/plugins/tasks.lua` | задачи из Zed: `up`, air, тесты, покрытие, линтер, compose, docker build, hadolint, trivy, govulncheck, `dot` |
| `lua/dotfiles/http.lua` | **Postman в файле**: `.http`-запросы через curl, без плагинов и лицензий |
| `lua/dotfiles/endpoints.lua` | эндпоинты Gin, как окно Endpoints в GoLand (`пробел r e`) |
| `lua/plugins/dotfiles.lua` | тема tokyonight night с прозрачным фоном — в тон терминалу |
| `lazyvim.json` | включённые «extras»: Go, Docker, YAML, JSON, Markdown, отладчик, тесты |
| `lazy-lock.json` | точные версии всех плагинов — на другом маке встанет то же самое |

`install.sh` ставит ссылку `~/.config/nvim → nvim/`. Прежний самодельный `init.lua` сохранён как
`~/.config/nvim.bak-20261014`. Плагины и инструменты живут вне репозитория: `~/.local/share/nvim`.

## Первый запуск

```bash
nvim .            # в папке проекта
```

Первый запуск сам докачает недостающее: парсеры подсветки собирает `tree-sitter-cli` (есть в Brewfile),
языковые серверы и утилиты ставит Mason (`:Mason` — список, статус, переустановка).
Уже стоят: gopls, delve, golangci-lint, gofumpt, goimports, серверы для Lua, YAML, JSON, Dockerfile, compose, Markdown.

## Vim с нуля: 20 команд на первую неделю

Vim — режимы. **Обычный** (`esc`) — ходишь и командуешь, **вставка** (`i`) — печатаешь, **выделение** (`v`, `V`) — выделяешь.
Команда = действие + куда: `d` (удалить) + `w` (до следующего слова) = `dw`. Цифра впереди повторяет: `3dd`.

| | Клавиши | Что |
|---|---|---|
| ходить | `h j k l` · `w` / `b` · `0` / `$` · `gg` / `G` | ←↓↑→ · слово вперёд / назад · начало / конец строки · начало / конец файла |
| | `{` / `}` · `ctrl-d` / `ctrl-u` · `s` + 2 буквы | абзац · полэкрана · прыжок в любое место (flash) |
| печатать | `i` / `a` · `o` / `O` · `esc` | перед / после курсора · новая строка ниже / выше · выйти |
| менять | `x` · `dd` · `dw` · `cw` · `ciw` · `ci"` | символ · строка · слово · заменить слово · всё слово под курсором · текст в кавычках |
| | `yy` · `p` · `u` · `ctrl-r` · `.` | копировать строку · вставить · отменить · вернуть · **повторить последнее** |
| искать | `/текст` → `n` / `N` · `*` | найти, дальше / назад · слово под курсором |
| файлы | `:w` · `:q` · `пробел f f` · `пробел e` | сохранить (не нужно — автосохранение) · выйти · найти файл · дерево |

Учиться: `:Tutor` — встроенный урок на 30 минут. Неделю живёшь на этой таблице — дальше пальцы сами.

## Главное — пробел

`пробел` (leader) открывает меню всех действий с подсказками, держать в голове ничего не нужно.

| Клавиши | Что |
|---|---|
| `пробел f f` · `пробел /` · `пробел ,` | файл по имени · текст по проекту · открытые буферы |
| `пробел e` | дерево файлов |
| `gd` · `gr` · `gI` · `K` | определение · где используется · реализации · документация |
| `пробел c r` · `пробел c a` | переименовать · действия с кодом (исправления, рефакторинги gopls) |
| `пробел x x` | все проблемы списком (Trouble) |
| `пробел t r` · `пробел t t` · `пробел t s` | тест под курсором · тесты файла · панель тестов |
| `пробел d b` · `пробел d c` · `пробел d O` / `d i` / `d o` · `пробел d t` | точка останова · запустить/дальше · шаг / внутрь / наружу · стоп |
| `пробел g g` · `пробел r d` | lazygit · lazydocker |
| `пробел r e` | **эндпоинты Gin** с полным путём (префиксы `Group` складываются сами): `enter` — к хендлеру, `ctrl-r` — **отправить запрос** (ответ справа, токен после логина подставляется сам, `q` — закрыть), `ctrl-y` — скопировать `curl` |
| `пробел r r` · `пробел r l` | задачи как `ctrl-r` в Zed · что запущено и чем кончилось |
| `V` … `J` / `K` | выделенные строки вниз / вверх (`alt-j/k` занял AeroSpace) |
| `пробел s k` | поиск по всем клавишам |
| `пробел D` | **база проекта**: таблицы, запросы, результат таблицей (адрес — как у `db`: из `.env` или по имени папки) |
| `пробел r c` | **контейнеры** — `orbstack` во всплывающем окне |
| `пробел r p` · `пробел r w` · `пробел r b` | `dot project doctor` · `dot work` · `dot backup` |
| `пробел g b` | **история строки**: кто и когда её менял, `enter` — весь коммит |
| `пробел g p` · `пробел g i` | **pull requests и issues** GitHub (через `gh`): diff, комментарии на строках, ревью |

Dockerfile проверяется hadolint прямо при наборе — замечания как обычные ошибки. В статусной строке — `◆ режим 1ч12м`, когда включён `dot work`.

## Само, без `:w`

- **Автосохранение:** вышел из режима вставки, поправил что-то в обычном режиме, ушёл в другое окно — файл записан.
- **Импорты расставляются сами** при каждой записи: goimports добавляет нужные (и стандартные, и из `go.mod` — gin и т.п.)
  и убирает лишние, gofumpt форматирует. Автодополнение пакета тоже сразу добавляет импорт.
- **Правки снаружи подхватываются сами:** Claude Code, `git pull`, `go generate` — буфер перечитается после паузы в наборе.
- Выключить автосохранение на время: `:let g:autosave = v:false`.
- **Neovim — редактор по умолчанию** (`$EDITOR`): `git commit`, `e` в lazygit (сразу на нужной строке), yazi, `crontab -e`.

## Postman в файле

`пробел r h` собирает `api.http` в корне проекта: все маршруты Gin запросами, логин первым. Дальше файл твой —
правь тела и параметры. Курсор на запрос → `enter` — ответ справа (JSON, статус, время), `q` — закрыть.

```http
@host = http://localhost:8080

### POST /auth/login
# @name login
POST {{host}}/auth/login
Content-Type: application/json

{"email": "me@example.com", "password": "secret"}

### GET /api/me — токен из ответа логина подставится сам
GET {{host}}/api/me
Authorization: Bearer {{login.response.body.$.access_token}}
```

`пробел R r` — повторить последний, `пробел R c` — скопировать как curl, `пробел R n` / `R p` — соседний запрос.
Работает и с любыми `.http` из VS Code или GoLand. Плагин kulala из LazyVim не используется: с 2026 он требует платную лицензию.

## Русская раскладка

Язык переключать не нужно: в обычном режиме русские буквы работают как английские на тех же клавишах.
`о`/`л` — вниз/вверх (`j`/`k`), `вв` — удалить строку (`dd`), `ц` — к следующему слову (`w`), `Ж` — команда (`:`),
`Жц` + `enter` — сохранить. В режиме вставки буквы печатаются как есть.

## Отладка как в GoLand

| Клавиши | Что |
|---|---|
| `F9` | запустить / дальше |
| `F8` · `F7` · `shift-F8` | шаг · внутрь · наружу |
| `ctrl-F8` | точка останова |

F-клавиши на маке — через `fn`. То же самое есть и на `пробел d …`.

## Поменять

- **Язык или фича:** `:LazyExtras` — включить одной клавишей (запишется в `lazyvim.json`, закоммить).
- **Свой плагин или настройка плагина:** новый файл в `lua/plugins/` — LazyVim сам его подхватит.
- **Свои клавиши и опции:** `lua/config/keymaps.lua` и `options.lua`.
- **Обновить плагины:** `:Lazy update`, потом закоммить `lazy-lock.json`.
