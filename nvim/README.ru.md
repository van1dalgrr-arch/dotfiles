# nvim

🇬🇧 [English version](README.md) · [← dotfiles](../README.ru.md)

Neovim на [LazyVim](https://lazyvim.org) — запасной выход, если Rune или Zed надоели: готовая IDE в терминале,
ничего не нужно собирать руками. Свою сборку с нуля потом можно начать в соседней папке и запускать через
`NVIM_APPNAME=<имя> nvim` — эта при этом не сломается.

| Файл | Что это |
|---|---|
| `init.lua` | одна строка: грузит `lua/config/lazy.lua` |
| `lua/config/lazy.lua` | ставит менеджер плагинов lazy.nvim и LazyVim; **проверка обновлений в фоне выключена** — обновить: `:Lazy update` |
| `lua/config/{options,keymaps,autocmds}.lua` | свои настройки поверх LazyVim (пока пустые — всё из коробки) |
| `lua/plugins/dotfiles.lua` | тема tokyonight night с прозрачным фоном — в тон терминалу |
| `lazyvim.json` | включённые «extras»: Go, Docker, YAML, JSON, Markdown, отладчик, тесты |
| `lazy-lock.json` | точные версии всех плагинов — на другом маке встанет то же самое |

`install.sh` ставит ссылку `~/.config/nvim → nvim/`. Прежний самодельный `init.lua` сохранён как
`~/.config/nvim.bak-20261014`. Плагины и инструменты живут вне репозитория: `~/.local/share/nvim`.

## Первый запуск

```bash
nvim .            # в папке проекта
```

Первый запуск сам докачает недостающее: парсеры подсветки собирает `tree-sitter-cli` (есть в Brewfile),
языковые серверы и утилиты ставит Mason (`:Mason` — список, статус, переустановка).
Уже стоят: gopls, delve, golangci-lint, gofumpt, goimports, серверы для Lua, YAML, JSON, Dockerfile, compose, Markdown.

## Главное — пробел

`пробел` (leader) открывает меню всех действий с подсказками, держать в голове ничего не нужно.

| Клавиши | Что |
|---|---|
| `пробел f f` · `пробел /` · `пробел ,` | файл по имени · текст по проекту · открытые буферы |
| `пробел e` | дерево файлов |
| `gd` · `gr` · `gI` · `K` | определение · где используется · реализации · документация |
| `пробел c r` · `пробел c a` | переименовать · действия с кодом (исправления, рефакторинги gopls) |
| `пробел x x` | все проблемы списком (Trouble) |
| `пробел t r` · `пробел t t` · `пробел t s` | тест под курсором · тесты файла · панель тестов |
| `пробел d b` · `пробел d c` · `пробел d O` / `d i` / `d o` · `пробел d t` | точка останова · запустить/дальше · шаг / внутрь / наружу · стоп |
| `пробел g g` | lazygit |
| `пробел s k` | поиск по всем клавишам |

## Поменять

- **Язык или фича:** `:LazyExtras` — включить одной клавишей (запишется в `lazyvim.json`, закоммить).
- **Свой плагин или настройка плагина:** новый файл в `lua/plugins/` — LazyVim сам его подхватит.
- **Свои клавиши и опции:** `lua/config/keymaps.lua` и `options.lua`.
- **Обновить плагины:** `:Lazy update`, потом закоммить `lazy-lock.json`.
